# 如何同时登录同一网站的两个账号？

同一张测试订单，管理员能改状态，普通成员只能查看。用 **「指纹浏览器」** 分别给这两种角色建环境，就能同时保留两个网页窗口，直接对照菜单和账号名。先让名称能区分角色，再检查各自的登录状态。

## 建一对可辨认的测试身份

在指纹浏览器里新建两个普通环境，分别命名为「验收－管理员」和「验收－成员」。在各自窗口访问同一个测试地址，各用相应的授权测试账号登录。不要把两个身份先后登录在同一个窗口里。[桌面环境说明](https://zwbrowser.com/help/desktop/environments/)

![两套环境从不同的工作台行打开](https://zwbrowser.com/images/desktop-guide-open-list-light.webp)

| 操作 | 管理员窗口应观察什么 | 成员窗口应观察什么 |
| --- | --- | --- |
| 首次打开后台 | 头像、账号名、管理员菜单 | 头像、账号名、普通成员菜单 |
| 两边都刷新 | 当前身份是否保留 | 当前身份是否保留 |
| 只关闭管理员窗口再重开 | 是否需要重新验证 | 原成员页面是否仍可继续 |

## 遇到两个页面显示同一名字

先从工作台分别定位两个窗口，在各自窗口看网站头像。名称写错、打开了同一行、两个测试账号本来就属于同一用户，是三种不同原因。如果网站采用统一登录，退出操作也可能影响服务器上的会话。用演示账号做这一步，以网站端的实际结果为准。

Ghost Browser 还提供以身份组织网页会话的做法。比较两种界面时，让接手同事只看窗口和标签，判断能不能在第一次尝试时回到正确账号。[Ghost Browser 官网](https://ghostbrowser.com/)
